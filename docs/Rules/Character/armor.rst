.. _armor:

Armor
=====

**Armor** provides a character with a "static buffer" against incoming trauma, reducing the number of points lost from their **Character Resources** when they suffer a hit.

*   **Physical Armor:** Protects against kinetic force, blades, and blunt trauma. It provides **Physical Armor**.
*   **Ephemeral Armor:** Protects against magical, spiritual, or mental trauma. It provides **Ephemeral Armor**.

**Damage Reduction (DR)**
-------------------------

When a character suffers damage, their relevant Armor value is subtracted from the total before it affects their pools. Some specialized attacks or techniques may **Bypass** or **Sunder** Armor, ignoring this protection entirely.
